# Supply Chain Sales Dashboard

## Overview
An interactive Power BI dashboard built to explore sales performance across product categories, products, and countries.

## Tools Used
- Excel
- Python
- SQL
- Power BI

## Key Metrics
- **Total Revenue:** €3.60K
- **Total Units Sold:** 924
- **Average Order Value:** €13.73

## Dashboard Visualizations
- **Revenue by Product Category:** Compares revenue from Vegetables and Fruit.
- **Units Sold by Product:** Compares product sales volumes.
- **Revenue Share by Country:** Shows the revenue contribution of Belgium, the Netherlands, and France.

## Workflow
1. Prepared and analyzed data using Excel, Python, and SQL.
2. Exported processed data into CSV files.
3. Imported the CSV files into Power BI.
4. Created KPI cards and charts to visualize sales performance.

## Project Files
- `dashboard/` — Power BI report
- `data/` — processed CSV files
- `scripts/` — Python scripts
- `images/` — dashboard screenshot

## Summary
This project demonstrates data preparation, data querying, KPI analysis, and business intelligence dashboard development.
